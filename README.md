#  Symptom Checker Application

This is a frontend health web application that allows users to input their symptoms and receive possible conditions, health recommendations, follow-up questions, and emergency alerts. It uses the **AI Doctor API** for health insights based on symptoms. This application is built with HTML, CSS, and JavaScript.

# Features

. Input symptoms (e.g., "I have a fever")
. Recommendations and follow-up health tips based on the symptoms
. Emergency detection (e.g., chest pain, fainting)
. Responsive design for mobile devices
. Educational warnings and resource references

# Setup

git clone <repository-url>

 cd symptom-checker

 # Usage

 User inputs symptoms (e.g., "I have a fever")

 Clicks on check symptoms and is given health insights, recommendations, follow-up questions and warnings.

 # API Reference
 
This application uses the AI Doctor API. For more information, visit: https://rapidapi.com/bilgisamapi-api2/api/ai-doctor-api-ai-medical-chatbot-healthcare-ai-assistant
